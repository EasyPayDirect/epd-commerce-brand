# Capabilities

EPD Commerce describes what it does with four capability names, always in this order:

1. **Transact**
2. **React**
3. **Analyze**
4. **Create**

Payments come first. Transact is the foundation everything else is built on.

## Rule

The capability names are approved only with an explanation next to them. Never use a capability name on its own as a label, eyebrow, pill, or headline. Always pair it with its one-line promise and at least one supporting line from its file below.

| File | Capability | Promise |
|---|---|---|
| [01-transact.md](01-transact.md) | Transact | Payments first: the right merchant account and the ways buyers want to pay |
| [02-react.md](02-react.md) | React | Protect the revenue you already earned |
| [03-analyze.md](03-analyze.md) | Analyze | Chat with your data. Let The Professor take action. |
| [04-create.md](04-create.md) | Create | Products, subscriptions, and AI-optimized pages |

The wording in these files is approved. Shorten it if a format needs fewer words, but do not add capabilities, rename them, or change their order.
