# Capabilities

EPD Commerce describes what it does with four capability names. The default order is **CART**:

1. **Create**
2. **Analyze**
3. **React**
4. **Transact**

The order can change to fit the content. For example, put Transact first in payments-led content. There is no fixed order.

## Rule

The capability names are approved only with an explanation next to them. Never use a capability name on its own as a label, eyebrow, pill, or headline. Always pair it with its one-line promise and at least one supporting line from its file below.

| File | Capability | Promise |
|---|---|---|
| [create.md](create.md) | Create | Products, subscriptions, and AI-optimized pages |
| [analyze.md](analyze.md) | Analyze | Chat with your data. Let The Professor take action. |
| [react.md](react.md) | React | Protect the revenue you already earned |
| [transact.md](transact.md) | Transact | Payments first: the right merchant account and the ways buyers want to pay |

The wording in these files is approved. Shorten it if a format needs fewer words, but do not add capabilities or rename them.
