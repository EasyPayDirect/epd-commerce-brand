# Transact

One system for every way you get paid, by people or by agents.

## The Transact promise

Money movement is the core job of a commerce platform. Transact is where every path a dollar can take through EPD Commerce lives, whether the buyer is a person clicking Buy or an agent calling the MCP server. One catalog, one customer record, one reporting surface. No side systems to reconcile.

## Features that live in Transact

- Hosted Checkout
- Post Purchase Screen
- Easy Charge
- REST API
- MCP Server
- API Keys
- Webhooks
- Integrations

## Key message

One system for every way you get paid. By people. By agents. Hosted Checkout with a live preview builder. Easy Charge for phone sales. One REST API and one MCP server so Claude, Cursor, or your own LLM agent can run real commerce tasks against typed tools. One catalog, one customer record, no side systems to reconcile.
