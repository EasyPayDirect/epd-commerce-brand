## Before partner use

Replace each file with the brand owner's official mark and record the source and that brand's usage guidelines here. Each brand's own rules apply (clearspace, minimum size, allowed colors, acceptance-mark wording). Until then, the Payments benefit template uses these marks only in EPD Commerce-produced graphics.

## Rules

- Never generate, redraw, or alter a payment-method mark.
- Show marks at equal optical height, evenly spaced, in white or their allowed single color on dark.
- Show only methods available on both processing options: cards, Apple Pay, Google Pay, PayPal, Venmo, ACH, Splitit, Klarna, Afterpay, Sezzle.
